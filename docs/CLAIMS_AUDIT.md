# Drishti — Resume Claims Audit

Audited: 2026-11-19, against branch `main` @ `0dd4779` (2 commits, both authored 19 Feb 2026).
Method: read every source file (33 tracked files, ~1,900 lines of JS/JSX), grepped for ML / metric / secret terms, inspected git history.
Not run: the seed script and the server. `node`, `docker` and `gcloud` are not installed on this machine (`python3` 3.14.8 and `gh` are), so every row below is from static reading of the code, not from running it. Where a number could only be measured by running, the row says so.

## Headline finding

**The repository is not the project the resume describes.** It is a **React 19 + Vite + Tailwind front end over an Express + SQLite (better-sqlite3) API, filled with randomly generated demo data.** There is no Python, no scikit-learn, no FastAPI, no PostgreSQL, no ML model, no training or evaluation code, and no labels (there is no "defaulted" column anywhere). The "risk score" is a hand-written formula applied at seed time (`server/seed.js:54-63`). A precision figure cannot be computed for it because nothing is predicted and there is nothing to compare against.

If the Python / FastAPI / scikit-learn version exists, it is not in this repo or its history. If it does, point me to it. If not, the plan below builds it for real.
